🧩 Architecture Overview
Sucram 2.0 is built on five core modules:

- Identity Discovery Module (IDM)  
- Threat Detection Engine (TDE)  
- Session Monitoring Module (SMM)  
- Device Intelligence Module (DIM)  
- Policy Engine Module (PEM)  

Each module is independently deployable and designed for enterprise‑grade scalability.

---

🔐 Identity Discovery Module (IDM)
The IDM establishes the true identity behind every interaction using device, network, behavioral, and session‑level signals.

Capabilities include:
- Identity confidence scoring  
- Behavioral pattern analysis  
- Device & network fingerprinting  
- Anomaly detection  
- Risk‑based identity verification  

---

🛡️ Threat Detection Engine (TDE)
The TDE is Sucram’s real‑time security core, correlating identity, device, session, and network signals to detect threats and trigger automated responses.

Threat levels include:
- Low — log only  
- Medium — challenge  
- High — block + notify  
- Critical — immediate lockdown  

---

📡 Session Monitoring Module (SMM)
Tracks user activity across devices, networks, and time to detect abnormal behavior and unauthorized access.

Capabilities:
- Real‑time session tracking  
- Multi‑device correlation  
- Privilege escalation detection  
- Automated session responses  

---

🖥️ Device Intelligence Module (DIM)
Evaluates the trustworthiness of every device interacting with Sucram 2.0.

Includes:
- Hardware fingerprinting  
- OS & browser validation  
- Security posture scoring  
- Device trust score (0–100)  

---

⚖️ Policy Engine Module (PEM)
Defines how Sucram responds to identity, device, session, and network events.

Outcomes:
- ALLOW  
- BLOCK  
- REVIEW  
- RETRY
