> **Detect. Block. Eliminate.** — The cybersecurity suite built for the modern threat landscape.

Sucram 2.0 is an open-source, unified cybersecurity suite that detects, blocks, and removes hacking attempts in real time. Built for individuals, developers, and small businesses who deserve enterprise-grade protection — without the enterprise-grade price tag.

---

## ✨ Features

- 🔍 **Real-Time Detection** — AI-powered scanning identifies intrusion attempts the moment they occur
- 🧹 **Automated Removal** — One-click threat elimination with a full audit trail
- 🔓 **Open-Source Core** — Apache 2.0 licensed for full community transparency
- 🪶 **Lightweight Deployment** — Runs on any system with no enterprise infrastructure needed
- 🏦 **Account Takeover Shield** — Specialized protection for financial accounts and payment systems
- 📊 **Detailed Reporting** — Every event logged, timestamped, and exportable

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/YOUR_ORG/sucram.git

# Navigate into the project
cd sucram

# Install dependencies
npm install   # or pip install -r requirements.txt

# Run Sucram 2.0
npm start     # or python sucram.py
